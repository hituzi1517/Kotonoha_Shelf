# ことのは書架

シリーズ → 章 → 話の順に作り、話の本文欄に文章を貼り付けます。
文字数は本文の空白を含め、改行を除いて数えます。
章・シリーズのコピーには Markdown 形式の見出しが付きます。

## GitHub Pages

1. ZIPを解凍し、index.html、style.css、app.js、.nojekyll をリポジトリのルートに配置します。
2. リポジトリの Settings → Pages で、ブランチからの公開を選び、ファイルを配置したブランチと /(root) を指定します。
3. GitHub Pages が発行した HTTPS のURLを開きます。

## 自動保存と引っ越し

本文と本棚の構成は、利用中のブラウザに自動保存されます。入力した本文はリポジトリには書き込まれません。
端末・ブラウザ・公開先を変えるときは、「バックアップ」からJSONを書き出し、移行先で読み込んでください。読み込みは移行先の本棚を置き換えます。

## ホーム画面への追加

iPhone・iPadのSafariでサイトを開き、共有メニューから「ホーム画面に追加」を選び、「ウェブアプリとして開く」をオンにします。
Safariで入力済みのデータがホーム画面版に表示されない場合は、Safari側でバックアップを書き出して、ホーム画面版で読み込みます。

## Markdownで話を追加

章を開き、「Markdownで話を追加」を選びます。話の区切りには、先頭と同じ数の `#` を使います。

```markdown
# 第1話 朝

窓を開けた。

# 第2話 夜

星が見えた。
```

「内容を確認」でタイトルと文字数を確認し、「○話を追加」を押すと章の末尾に順番に追加されます。
